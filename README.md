# Eclipsia

A Fabric mod for Minecraft **26.2** that brings eclipses to the Overworld.

## Eclipses

Eclipses follow the moon, just like real ones:

| | When | What happens |
|---|---|---|
| **Solar eclipse** | Noon on the new moon, every 16 days (first one on day 5) | The moon slides over the sun. The sky turns deep blue-black, stars come out, sky light drops low enough for monsters to spawn, and undead stop burning. |
| **Blood moon** (lunar eclipse) | Midnight on the full moon, every 16 days (8 days after each solar eclipse) | The moon dims and the world's moonlight, fog and clouds turn blood red. |

Each eclipse has a partial phase that builds up to a short totality and then fades away. Titles and messages announce each stage.

The sky effects run through Minecraft's own timeline system (`data/eclipsia/timeline`), so the server and every client see the same sky. A small client mixin fades the sun and moon themselves.

### During an eclipse

- **Don't look at the sun.** Staring up at a solar eclipse without eye protection blinds you for a few seconds.
- **Eclipse-touched monsters.** Monsters that appear during an eclipse gain Speed, and during a blood moon Strength too. When killed they can drop **Umbral Shards** (solar) or **Sanguine Shards** (lunar).

## Items and blocks

| | Recipe | Use |
|---|---|---|
| Eclipse Glasses | 2 iron nuggets, 2 tinted glass, string | Wear on your head to watch a solar eclipse safely. |
| Eclipse Almanac | Book + clock (shapeless) | Use it to see how long until the next solar and lunar eclipse. |
| Umbral Shard / Sanguine Shard | Dropped by eclipse-touched monsters | Crafting material. |
| Block of Umbra / Block of Sanguine | 9 shards | Decorative storage blocks. |
| Corona Lamp | 3 umbral shards, glowstone, sanguine shard | Light level 15 block shaped like a total eclipse. |

There are also advancements to earn: standing in the path of totality, surviving a blood moon, looking at the sun (don't), and watching it safely.

## Commands

`/eclipse` shows the schedule and the exact `/time add` value that jumps to each eclipse, which is handy for testing.

## Building

Requires JDK 25.

```sh
./gradlew build          # jar goes to build/libs/
./gradlew runClient      # launch a dev client
```

The eclipse timings, timelines, textures and data files are generated by `tools/generate.py` (needs Pillow). Change the schedule there and rerun it.
